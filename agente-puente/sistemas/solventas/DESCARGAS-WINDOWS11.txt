A. OBLIGATORIO (bajalo en el Windows 11)
----------------------------------------------------------------------------
1) SQL Server 2022 Express  (Microsoft, gratis)  <- LA QUE SE USA
   - La 2019 Express ya no se puede descargar. La 2022 funciona igual con la
     base de Solventas (el servidor lo probe con tu respaldo).
   - Que buscar: "SQL Server 2022 Express" en la pagina de descargas de
     SQL Server de Microsoft (microsoft.com/sql-server). El archivo se llama
     algo como SQL2022-SSEI-Expr.exe (baja el resto al instalar).
   - Al instalar elige el tipo "Basica". Deja el nombre de instancia como esta
     (SQLEXPRESS). No hace falta instalar SSMS.
   - Despues de instalar, el paquete trae habilitar-red-sql.bat, que enciende
     lo que el conector viejo de Solventas necesita.

2) El paquete de traslado que te mande (solventas-traslado-windows11.zip)
   Trae los scripts para restaurar la base y dejarla lista. Descomprimelo en
   C:\SSCA.

3) El respaldo NUEVO de la base (RRVS2013CA-....bak), el que sacas en el
   Windows 8.1 el dia del traslado. Ya tienes uno de hoy (RRVS2013CA-hoy.bak)
   para las pruebas.

C. SOLO SI Solventas LO PIDE (no lo bajes antes)
----------------------------------------------------------------------------
1) BDE - Borland Database Engine (Embarcadero, gratis)
   - Solo si al abrir Solventas dice algo como "BDE", "Borland Database
     Engine" o "IDAPI32.DLL".
   - Que buscar: "Embarcadero BDE installer" / "BDE 5.2 redistributable".
   - Como instalarlo y que hacer despues lo vemos juntos: no basta con copiar
     la carpeta, a veces hay que instalarlo como administrador.

2) Driver de la impresora fiscal y del cable USB-serial
   - Solo si Windows 11 no la reconoce. Busca el driver en la pagina del
     FABRICANTE (la marca esta en la etiqueta; el programa usa tfhkaif.dll, de
     la familia "The Factory HKA / Tfhka"). El cable puede necesitar driver
     FTDI, CH340 o Prolific segun su chip.
   - Dime la marca y el modelo y te digo cual.
